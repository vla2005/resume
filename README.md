## 🚀 Como Funciona a Automação

Este repositório utiliza o **GitHub Actions** (`.github/workflows/release.yml`).  
Sempre que um novo commit é enviado para a branch `main`, a ação:
1. Detecta os arquivos atualizados em `pdfs/`.
2. Publica ou atualiza automaticamente a release com a tag permanente **`latest`**.
3. Disponibiliza os links de download direto que são consumidos pelo portfólio oficial ([viktorware.com](https://viktorware.com/)).
